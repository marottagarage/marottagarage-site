Données collectées

Ce site ne contient ni formulaire, ni compte client, ni outil de statistiques. Nous recevons uniquement les données que vous nous transmettez vous-même par téléphone ou par e-mail, et nous les utilisons seulement pour répondre à votre demande.

Hébergement

Le site est hébergé par GitHub Pages (GitHub, Inc.). Comme tout hébergeur, GitHub enregistre des données techniques de connexion (adresse IP, date, page consultée) pour assurer la sécurité du service.

Contenus de tiers

Certaines pages affichent des contenus fournis par des tiers : la carte (Google Maps), la liste de nos véhicules (Autolina) et les polices d'écriture (Google Fonts). Lorsque vous consultez ces pages, votre navigateur se connecte à ces services, qui peuvent traiter votre adresse IP selon leur propre politique de confidentialité.

Vos droits
